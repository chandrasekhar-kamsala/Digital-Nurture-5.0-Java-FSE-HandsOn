# Cognizant Java FSE Deep Skilling

This repository contains all mandatory hands-on exercises completed as part of the Cognizant Digital Nurture 5.0 Java Full Stack Engineering (Java FSE React) Deep Skilling Program.

* Data Structures and Algorithms
* Design Patterns
* PL/SQL
* JUnit & Mockito
* Spring Core

* Microservices
* React
* Git
* Docker
* Agile
